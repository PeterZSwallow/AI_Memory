# Витрина / Vitrina: маркетплейс объявлений с AI

MVP доски объявлений в духе Avito, eBay и Craigslist. Классический маркетплейс здесь дополнен AI на каждом шаге сделки. Интерфейс полностью двуязычный (RU/EN).

## Питч в одном абзаце

Классические доски объявлений не меняются уже 15 лет: продавец 5 минут заполняет форму, покупатель вручную настраивает фильтры, а мошенники уводят людей в мессенджеры. Витрина устроена иначе. Продавец фотографирует вещь, и **за ~10 секунд** AI пишет название, описание и характеристики, подбирает категорию и рыночную цену, а также переводит объявление на английский. Покупатель ищет **обычной фразой**, например «айфон до 50 тысяч в Москве в хорошем состоянии», и AI сам превращает её в точные фильтры. **AI-антифрод** проверяет каждое объявление и каждое сообщение в чате.

## Что есть в MVP

| Для пользователя | Для инвестора / бизнеса |
|---|---|
| Главная: категории, VIP- и свежие объявления | Дашборд `/insights` с живыми метриками из БД |
| Поиск на естественном языке, фильтры, сортировка, пагинация | GMV, активные объявления, пользователи, доля AI-объявлений |
| Карточка объявления: галерея, характеристики, AI-оценка цены | Рост контактов неделя к неделе (WoW), воронка «просмотры → контакты» |
| Создание объявления из фото с помощью AI | Время создания объявления: AI против ручного ввода |
| Чат покупателя и продавца, индикатор прочтения, AI-флаги | Топ AI-запросов, география, категории |
| Избранное, «мои объявления», статусы (продано / архив) | Модель монетизации: платное VIP-продвижение (кнопка уже работает) |
| Профили продавцов, рейтинг, отзывы, «проверенный продавец» | Антифрод: число заблокированных объявлений |
| Регистрация и вход, демо-вход в один клик | Автоперевод RU⇄EN открывает трансграничную торговлю |

### AI-функции (`src/lib/ai.ts`)

1. **Объявление из фото.** Claude vision получает 1–4 фото и возвращает категорию, название и описание на RU и EN, состояние, характеристики и рекомендуемую цену. Ответ сразу приходит структурированным.
2. **Поиск на естественном языке.** Запрос превращается в `{keywords, category, city, priceMin, priceMax, condition, delivery, sort}`. Пользователь видит, как AI понял запрос, и может снять любой фильтр.
3. **Оценка цены.** Берутся процентили 25/50/75 по похожим объявлениям в той же категории и с той же моделью. Если похожих меньше трёх, цену оценивает AI.
4. **Антифрод.** Эвристики (предоплата, мессенджеры, ссылки, запрещённые товары, цена сильно ниже рынка) работают вместе с AI-оценкой риска. При риске ≥ 70 объявление блокируется. Подозрительные сообщения в чате помечаются.
5. **Автоперевод.** Каждое объявление хранится на двух языках, оригинал можно открыть одной кнопкой.

**Без ключа API всё работает.** Если `ANTHROPIC_API_KEY` не задан, поиск переключается на встроенный rule-based парсер, а антифрод — на эвристики. Создание из фото в этом режиме возвращает шаблон-заглушку и предлагает подключить ключ. Демо не сломается на встрече с инвестором из-за сети.

## Стек

- **Next.js 15** (App Router, Server Components, Server Actions) + **React 19** + **TypeScript**
- **PostgreSQL** + **Drizzle ORM**: полнотекстовый поиск через `tsvector` с русской и английской морфологией, GIN-индексы
- **Claude API** (`@anthropic-ai/sdk`): структурированные ответы и server-side fallback при отказах модели
- **Tailwind CSS v4**, `lucide-react`, `recharts`
- Авторизация: свои сессии (scrypt + httpOnly cookie, токены хранятся в БД в виде sha256)
- Фото: S3-совместимое хранилище (AWS S3 / Cloudflare R2 / MinIO) или локальный диск. Перед загрузкой фото сжимаются в браузере.

## Быстрый старт

```bash
cd apps/marketplace
cp .env.example .env            # при желании впишите ANTHROPIC_API_KEY
docker compose up -d db         # PostgreSQL 16
npm install
npm run db:setup                # миграции + демо-данные
npm run dev                     # http://localhost:3100
```

Демо-аккаунт: **demo@vitrina.app / demo12345**. Есть также кнопка «Войти как демо-пользователь» на странице входа.

Полностью в Docker:

```bash
cd apps/marketplace
ANTHROPIC_API_KEY=sk-ant-... docker compose up -d --build
docker compose run --rm app npx tsx src/db/migrate.ts
docker compose run --rm app npx tsx src/db/seed.ts
```

### Демо-данные

`npm run db:seed` создаёт детерминированный набор данных:

- 31 пользователь;
- 250+ объявлений в 12 категориях и 8 городах;
- переписки и отзывы;
- около 27 тыс. аналитических событий за 60 дней с ростом, чтобы графики на `/insights` выглядели живыми.

Все объявления вымышленные. Фото подгружаются с Unsplash, а если картинка недоступна, вместо неё показывается фирменная заглушка категории.

## Сценарий демо для инвесторов (3 минуты)

1. **Главная.** Ценностное предложение и живая статистика.
2. **Поиск.** Нажмите на пример «айфон до 50 тысяч в Москве» и покажите плашку «AI понял запрос как…».
3. **Карточка.** AI-оценка цены на шкале рынка, профиль и рейтинг продавца.
4. **«Разместить».** Загрузите фото, нажмите «Заполнить с помощью AI» и покажите время в секундах. Затем опубликуйте.
5. **Антифрод.** Создайте объявление с текстом «только предоплата на карту, пишите в телеграм»: оно блокируется автоматически.
6. **Переключатель EN.** Весь сайт и все объявления на английском, цены дополнительно показаны в долларах.
7. **`/insights`.** GMV, рост WoW, «27× быстрее с AI», воронка, география.

## Структура

```
src/
  app/                 страницы (App Router) и server actions
    api/               загрузка фото, AI-черновик, оценка цены, polling чата
    insights/          дашборд метрик
  components/          UI-компоненты
  db/                  схема Drizzle, миграции, сид
  lib/
    ai.ts              все вызовы Claude
    heuristics.ts      офлайн-парсер запросов и антифрод-правила
    queries.ts         поиск, рыночная цена, выборки
    auth.ts, storage.ts, i18n.ts, dictionaries.ts
drizzle/               SQL-миграции
```
